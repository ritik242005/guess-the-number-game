# Number Guessing Game

# 1. Introduction
The Number Guessing Game is a simple
Python-based project where the computer
generates a random number between 1 and
100. The player tries to guess the
number within a limited number of attempts.

# 2. Objectives
- Practise Python programming.
- Understand loops and conditional statements.
- Learn how to use random numbers.
- Handle user input and invalid entries.

# 3. Features
- Three difficulty levels: Easy, Medium,
  and Hard.
- Random number generation from 1 to 100.
- Hints such as "Too high" and "Too low".
- Input validation for non-numeric entries.
- Displays the correct number when the
  player runs out of attempts.

# 4. Difficulty Levels

| Level | Attempts |
|-------|----------|
| Easy  | 15       |
| Medium| 10       |
| Hard  | 5        |

# 5. Technologies Used
- Programming Language: Python
- Editor: Visual Studio Code
- Module: random (Python standard library)

# 6. How to Run the Project
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

   python main.py

# 7. How to Play
1. Run the program.
2. Select a difficulty level (1, 2, or 3).
3. Enter a guess between 1 and 100.
4. Follow the hints provided.
5. Guess correctly before attempts run out.

# 8. Concepts Learned
- Variables and data types
- Random number generation
- While loops and if-else statements
- Dictionaries
- Exception handling using try-except
